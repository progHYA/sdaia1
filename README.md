## 📌 Project Overview

This project applies **Natural Language Processing (NLP)** and Machine Learning techniques to analyze customer reviews and classify them into two sentiment categories:

* 🟢 Positive
* 🔴 Negative

The project demonstrates a complete NLP workflow, starting from raw text data and ending with sentiment predictions.
